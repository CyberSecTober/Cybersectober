# Templates

Starter templates for contributions. Copy the one that fits your contribution into the appropriate track folder and fill it in.

- `guide.md` — security guide or tutorial
- `checklist.md` — security checklist
- `resource-list.md` — curated list of free resources
- `translation.md` — translation of existing content
- `lab.md` — deliberately vulnerable lab environment
- `tool.md` — security tool or script
- `session-report.md` — report from a community awareness session
