# 🔐 CyberSecTOBER 2026

[![GitHub stars](https://img.shields.io/github/stars/CyberSecTober/Cybersectober?style=social)](https://github.com/CyberSecTober/Cybersectober/stargazers)

**Learn. Build. Contribute. Secure.**

CyberSecTOBER is a month-long open-source cybersecurity challenge for Cybersecurity Awareness Month. Together, we're building a free, community-owned library of security tips, guides, translations and labs that anyone can use.

> **Don't just learn cybersecurity. Contribute to it.**

⭐ **Star this repo** (top right of this page) to follow along and help more people find CyberSecTOBER.

## ⚡ Pick your level

| Time | What you do | What you get |
|---|---|---|
| **2 minutes** | Post a security tip on social media with **#CyberSecTOBER**, then [submit the link](https://forms.gle/placeholder) | 📣 Awareness Advocate badge |
| **5 minutes** | Add one tip to [`awareness/tips.md`](awareness/tips.md) in your browser, or [submit a tip](../../issues/new/choose) without any code | 🟢 First Contribution badge + your name in an open-source project |
| **15–60 minutes** | Pick an [open issue](../../issues) and build a guide, translation, checklist, lab or tool | Points, badges and a spot on the leaderboard |

**Spread awareness, contribute to open source, or both.**

## ✏️ Your first contribution in 5 minutes (no installs)

1. Open [`awareness/tips.md`](awareness/tips.md)
2. Click the ✏️ pencil icon (top right)
3. Add one security tip at the bottom, with your name
4. Click **Commit changes…** then **Propose changes**, then **Create pull request**

That's it. GitHub copies the project for you behind the scenes. A mentor reviews it, and when it's merged you get your badge. 🎉

| Contribution | Points |

## 🛡️ Safety first

Everything here is for **education and defense**. No malware, credential stealers, phishing kits, attacks on real organizations, real credentials or personal data. Labs must be deliberately vulnerable and run locally. Full rules in [CONTRIBUTING.md](CONTRIBUTING.md).
