# Scam Stories

Short **fictional** stories that show how a scam works and how to spot it. Stories stick in people's minds better than rules.

**How to add one:** create a new file in this folder named `your-github-username-short-title.md` (for example `ada-codes-fake-job-offer.md`) with:

1. A short story of **150 to 400 words** about a fictional person and a scam
2. **The red flags**: a list of the warning signs in the story
3. **The lesson**: what to do instead

Rules: everyone in the story must be fictional. Use made-up company names and `example.com` for any web addresses or emails. Never include real phone numbers, account numbers or real victims.
