# Security Quizzes

Short, fun quizzes that help people test what they know.

**How to add one:** create a new file in this folder named `your-github-username-topic.md` (for example `ada-codes-phishing.md`) with:

1. A title and who the quiz is for (students, small business owners, parents…)
2. **3 to 5 questions**, each with multiple-choice answers
3. An **answers section** at the bottom that explains why each answer is right

Keep it friendly, accurate and in your own words. Any examples must use fictional companies and `example.com`.
