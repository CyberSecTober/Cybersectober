# Cyber Awareness Track

Security tips, guides, checklists and infographics that help everyday users stay safe online.

**Topics:** phishing, scams, passwords, MFA, social engineering, safe browsing, mobile security, privacy.

**How to contribute:** Add a tip to `tips.md`, a term to `glossary.md`, a quiz to `quizzes/`, a fictional scam story to `stories/`, share a link to your #CyberSecTOBER social post in `posts.md`, write a guide, create a checklist, or design an infographic. Copy a template from `templates/` to get started.
